HAPPY BIRTHDAY MOM — 8 ตุลาคม 2569 (V3)
===================================
เว็บไซต์เซอร์ไพรส์สำหรับ "แม่" จาก "ลูกชายสุดหล่อ"
ธีมอบอุ่นครีม-ชมพู-ทอง | ใช้ Source Code จาก HappyBirthdaydekuann เดิม

เริ่มใช้งาน
1) แตกไฟล์ ZIP ให้เรียบร้อย
2) เปิด index.html ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ หรือเผยแพร่ขึ้นเว็บโฮสต์แบบ Static เพื่อให้แม่เปิดบนโทรศัพท์
3) รหัสเซอร์ไพรส์: 0810
4) เปิดซองจดหมายแล้วเลือกชม 8 ฉาก จะใช้ปุ่มลูกศร/จุดนำทางหรือปัดเปลี่ยนหน้าก็ได้
5) ควิซมี 3 คำถาม, มีหัวใจซ่อนอยู่ 21 ดวงและวงล้อคำอวยพรเป็นเกมเสริม ไม่จำเป็นต้องเก็บครบเพื่ออ่านจดหมาย
6) หน้าสุดท้ายสามารถบันทึกการ์ดเป็น PNG ได้
   - คอมพิวเตอร์: เบราว์เซอร์จะดาวน์โหลดไฟล์โดยตรง
   - โทรศัพท์: เว็บจะแสดงภาพตัวอย่างพร้อมปุ่ม 'บันทึกภาพการ์ด'; หากเครื่องไม่รองรับให้แตะภาพค้างเพื่อบันทึก

- นาฬิกาที่ใช้เป็นเวลาจากอุปกรณ์ผู้ชม จึงปรับด้วยการเปลี่ยนเวลาเครื่องได้

รูปภาพ
- ตอนนี้เป็นภาพตัวอย่าง SVG 4 ภาพ (assets/mom-photo-1.svg ถึง mom-photo-4.svg)
- เมื่อได้รับรูปแม่จริงแล้วให้นำภาพเข้าโฟลเดอร์ assets/ แล้วแก้ src และ data-full
  ของรูปแต่ละใบใน index.html ให้ตรงชื่อไฟล์ (เช่น assets/mom1.jpg)
- รูปที่ส่งขึ้นโฮสต์สาธารณะอาจถูกเข้าถึงโดยผู้อื่นได้ ควรใช้เฉพาะรูปที่แม่ยินยอมให้เผยแพร่

เพลง (ยังรอไฟล์ที่ผู้จัดทำจะส่งมา)
- V5 ยังไม่มีเพลงจริง และป้ายสถานะเพลงแสดงข้อความว่า 'รอเพลงที่ลูกเลือกให้แม่'
- เมื่อต้องเพิ่ม ให้ใส่ไฟล์ MP3 ของตัวเองลงใน assets/mom-song.mp3
- แก้แท็ก <audio id="memory-music" ...> ท้าย index.html เป็น
    <audio id="memory-music" src="assets/mom-song.mp3" preload="metadata" loop playsinline></audio>
- เปิดเพลงด้วยปุ่มบนเว็บหลังจากแม่เริ่มใช้งาน หากเบราว์เซอร์อนุญาต
- ปุ่มรูปเสียงมุมขวาบนใช้เปิด/ปิดเอฟเฟกต์เสียงได้แม้ยังไม่มีเพลง
- ใช้เพลงที่มีสิทธิ์นำมาเผยแพร่หรือได้รับอนุญาตเท่านั้น

ปรับแต่งเพิ่มเติม
- index.html     : ข้อความอวยพร ชื่อ รูปภาพ โครงสร้างแต่ละฉาก
- mom-theme.css  : สีและสไตล์อบอุ่น (โหลดทับ style.css เดิม)
- style.css      : เลย์เอาต์/แอนิเมชันจากต้นฉบับ
- script.js      : วันเปิด, รหัส, ควิซ, หัวใจ, วงล้อ, ดาวน์โหลดการ์ด

- ปรับหน้า 8 บนมือถือ ลดรูปช่อดอกไม้และเว้นช่องให้ปุ่มไม่อยู่ใต้แถบนำทาง
- เพิ่มหน้าต่างรูปการ์ดพร้อมปุ่มบันทึกสำหรับมือถือ

- ถอดเมนู Developer ที่เคยกด R สามครั้งเพื่อข้ามส่วนเซอร์ไพรส์

สิ่งที่เปลี่ยนจาก V2 เป็น V3 — Font Bug Fix & Smooth Performance
- แก้ต้นเหตุข้อความไทยซ้อน: ไม่แบ่งข้อความไทยเป็น span ทีละ Unicode code point อีกต่อไป
  ทำ Animation กับหัวข้อทั้งคำ จึงรักษารูปสระและวรรณยุกต์ได้ถูกต้อง
- ปรับ Layout หน้าอัลบั้มบนโทรศัพท์เป็น 2 คอลัมน์ตาม Document Flow
  ไม่ใช้ absolute position สำหรับรูปทั้ง 4 ใบ แก้รูป/ข้อความทับกัน และเลื่อนดูได้
- เพิ่มพื้นที่ว่างเหนือหัวข้อบนมือถือเพื่อไม่ให้ป้ายหัวใจและป้ายเพลงบังข้อความ
- เปลี่ยน Scene Transition จาก Blur + 3D rotate เป็น opacity + translate เท่านั้น
- ปิดการคำนวณการเอียงการ์ดทุกครั้งที่ Pointer Move / ลดอนุภาคที่สร้างเมื่อคลิก
- หยุด Animation ของฉากที่ไม่แสดงอยู่, ปิด Blur Layer ตกแต่งหลายชั้น
- บนมือถือหน้าจดหมายเลื่อนทั้งหน้าได้ในครั้งเดียว เพื่อไม่ต้องเลื่อนซ้อนในกล่อง
- เพิ่ม favicon.svg เพื่อไม่ให้ Local Server ตอบ 404 เพราะไม่มีไอคอน
- คงฉากทั้ง 8 ควิซ หัวใจ 21 ดวง วงล้อ บันทึกการ์ด และรหัส 0810 ตามเดิม
- รองรับ prefers-reduced-motion (ลดการเคลื่อนไหวตามการตั้งค่าของผู้ใช้)

วิธีตรวจบน Chrome DevTools
1) เปิด index.html ผ่าน Live Server เช่น http://127.0.0.1:5500/
2) เปิดเครื่องมือจำลองมือถือ เลือก iPhone 16 Pro Max (440 x 956)
3) ในแถบ Device Toolbar ตัวเลข Zoom 50% เป็นเพียงซูมภาพจำลองบนคอม
   เปลี่ยน 100% หรือ Fit to Window เพื่อดูขนาดการจำลองที่เหมาะสม
4) หาก Chrome ยังใช้ไฟล์ V2 อยู่ให้กด Ctrl+Shift+R เพื่อล้าง cache ของหน้านั้น
5) Performance แสดงเฟรมกระตุก / Main Thread / Event Log ตามเครื่องที่เปิดจริง
   ผลทดสอบ Chromium จำลองในเครื่องพัฒนา ไม่รับประกัน FPS บนโทรศัพท์ทุกรุ่น
