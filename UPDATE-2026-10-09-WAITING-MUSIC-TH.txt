การอัปโหลดขึ้น GitHub
1. แตก ZIP แล้วเลือกไฟล์และโฟลเดอร์ด้านในทั้งหมด (index.html ต้องอยู่ root ของ Repository)
2. อัปโหลดไฟล์เหล่านี้ทั้งหมดเข้า Repository เดิม แล้ว Commit changes
3. สำคัญ: อัปโหลด waiting-music.js, waiting-music.css และ assets/waiting-song.mp3 ไปด้วย
4. รอให้ GitHub Pages อัปเดต แล้วกด Ctrl+Shift+R เพื่อรีเฟรช
5. ตรวจสิทธิ์ในการเผยแพร่เพลงบนเว็บไซต์สาธารณะก่อนเผยแพร่
